# sgglobal
Skill Grow Institution (SG Skill) - Web Portal & Academic Management System

## Features
- **Student Admission System**: Multi-step registration wizard with OTP verification, document upload, and Razorpay payment.
- **Course Enrollment & Fee System**: Direct batch enrollment with Razorpay integration and distinct Enrollment ID generation per course.
- **Dynamic Course CMS**: 100% database-driven courses, categories, specs, roadmap curriculum, and fees.
- **Executive Admin Console**: Zero-shadow Bento design for managing admissions, course enrollments, course catalog, categories, and payment/SMTP gateways.
- **Automated Email Notifications**: PHPMailer integration for OTP, admission confirmation, and fee receipts.
- **Downloadable Fee Receipts**: Printable A4 fee receipts for both admissions and course enrollments.
